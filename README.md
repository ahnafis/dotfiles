# Dotfiles :rocket:

My desktop configuration files.

- **Shell:** [Bash](https://www.gnu.org/software/bash/)
- **Terminal emulator:** [Alacritty](https://github.com/alacritty/alacritty), [Tmux](https://github.com/tmux/tmux)
- **Text editor:** [Vim](https://github.com/vim/vim), Migrating to [Neovim](https://github.com/neovim/neovim)
- **Desktop environment:** [GNOME](https://gnome.org/)
